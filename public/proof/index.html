What TEOS Sentinel Shield Guard did, and what it doesn't do

Two real GitHub Actions runs, the test suites behind them, and the limits you should know before you add it to a pipeline. Action v5.1.0, engine v5.0.0.

A destructive command is blocked, and the next step never runs

Each run below is a manual workflow in the public repository. The Action scans a command string. The string is never executed.

Tests in the repository

test/rule-grid-test.js runs 16 cases and test/verdict-matrix.js runs 32 cases. Both pass with exit code 0 in the maintainer's run. They exercise a grid of rule categories and the verdict logic. They are not a separate test of each of the 258 rules.

The live service

The scan API reports its own status at /health: engine version, rule count (258), and the state of Redis. The engine is v5.0.0. The GitHub Action that calls it is v5.1.0, which is a separate version number.

Run the same check yourself

Add this to a workflow with workflow_dispatch. It needs an API key stored as the secret TEOS_API_KEY.

- uses: Elmahrosa/teos-sentinel-shield@v5.1.0
  with:
    api-key: ${{ secrets.TEOS_API_KEY }}
    scan-target: 'rm -rf /'
- run: echo "THIS MUST NEVER PRINT"

Before you rely on it

It calls a hosted API
The Action sends your scan-target text to the scan service and needs an API key. Keep secrets out of the scanned string.
It fails closed
If the API can't be reached, the step fails and later steps are skipped. Setting fail-open: 'true' reverses that, and we don't recommend it.
It is a gate, not an interceptor
The Action judges the string you give it and fails the job on BLOCK. It does not watch commands that run elsewhere in your pipeline.
Free tier limits
The free tier allows 100 requests per day. Beyond that the API returns HTTP 429 and the step fails. Paid tiers raise the limit.
Audit storage
Verdict records are stored in Redis. PostgreSQL was not configured at the last health check.
Deterministic by design
Verdicts come from fixed rules, not a language model. The same input and rule set are designed to give the same verdict.
