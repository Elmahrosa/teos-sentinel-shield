for AI Agentsجدار النار التنفيذي
لوكلاء الذكاء الاصطناعي

TEOS Sovereign Sentinel is a deterministic code/repository/agent execution pre-scanning firewall. Every command, script, or AI prompt is evaluated against 258 Active Governance Controls before execution. Decisions are binary and auditable: ALLOW, WARN, REVIEW, or BLOCK. حارس تيوس هو جدار ناري حتمي لفحص التعليمات البرمجية والمستودعات والوكلاء قبل التنفيذ. يتم تقييم كل أمر أو نص أو موجه ذكاء اصطناعي مقابل 258 قاعدة أمنية قبل التنفيذ. القرارات ثنائية وقابلة للتدقيق: السماح، التحذير، المراجعة، أو المنع.

Verdict Modelنموذج الحكم

4 Verdict Types.
No Grey Areas.4 أنواع من الأحكام.
لا مناطق رمادية.

Every scanned input receives one of four deterministic verdicts. No probability scores. No ML confidence thresholds. Every decision is rule-driven and auditable. كل إدخال يتم فحصه يتلقى واحداً من أربعة أحكام حتمية. لا نتائج احتمالية. لا عتبات ثقة للتعلم الآلي. كل قرار مدفوع بالقواعد وقابل للتدقيق.

ALLOW
No rule matched. Safe to proceed. Lowest risk.لم يتم مطابقة أي قاعدة. آمن للمتابعة. أقل مخاطرة.
WARN
Suspicious patterns detected. Caution advised.تم اكتشاف أنماط مشبوهة. يُنصح بالحذر.
REVIEW
Low-severity rule matched. Human review required.تم مطابقة قاعدة منخفضة الخطورة. المراجعة البشرية مطلوبة.
BLOCK
Deterministic rule matched. Execution prevented.تم مطابقة قاعدة حتمية. تم منع التنفيذ.

95 core rules cover destructive shell commands, secret exfiltration, SQL injection, command injection, path traversal, reverse shells, fork bombs, crypto miners, and supply chain attacks. 29 Solana rules detect anchor/BPF program vulnerabilities. 21 EVM rules cover reentrancy, flash loans, and centralization risks. 32 banking controls enforce governance for financial infrastructure, payment rails, and regulated banking environments. 8 dependency, 23 CI/CD, 25 token intelligence, and 25 due diligence rules complete the 258-control pack. 95 قاعدة أساسية تغطي أوامر الصدفة المدمرة، تسرب الأسرار، حقن SQL، حقن الأوامر، اختراق المسار، الصدف العكسية، قنابل الشوكة، عمال منجم العملات الرقمية، وهجمات سلسلة التوريد. 29 قاعدة سولانا تكتشف ثغرات برامج anchor/BPF. 21 قاعدة EVM تغطي إعادة الدخول، القروض الخاطفة، ومخاطر المركزية. 32 قاعدة بنكية تطبق الحوكمة على البنية التحتية المالية ومنصات الدفع والبيئات المصرفية الخاضعة للتنظيم. 8 قواعد تبعية و23 قاعدة CI/CD و25 قاعدة استخبارات الرموز الرقمية و25 قاعدة العناية الواجبة تكمل حزمة 258 قاعدة.

Every rule is deterministic — same input, same verdict. Scores: BLOCK ≥ 85, WARN ≥ 60, REVIEW below 60. Low-severity matches route to human review; clean input passes as ALLOW. كل قاعدة حتمية — نفس الإدخال، نفس الحكم. النقاط: منع 85 فأكثر، تحذير 60 فأكثر، مراجعة أقل من 60. المطابقات منخفضة الخطورة تُحال للمراجعة البشرية؛ الإدخال النظيف يمر كسماح.
