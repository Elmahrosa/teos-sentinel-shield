REST API Reference

Core Endpoints

Risk Scanning

Primary endpoints for code analysis, dependency scanning, and CI/CD pipeline security auditing.

POST/scanAnalyze code or shell commands for security risks

Request Body

{
  "code": "rm -rf /",
  "context": "telegram"
}
FieldTypeDescription
codestringCode or command to scan
contextstringOptional. Scan context (e.g. "telegram", "ci")

Response

{
  "verdict": "BLOCK",
  "score": 95,
  "ruleId": "R03",
  "severity": "CRITICAL",
  "reasons": ["Remote script piped to shell"],
  "findings": [{ "ruleId": "R03", "name": "CURL_EXEC_CHAIN", "score": 95, "severity": "CRITICAL" }]
}

ALLOW WARN BLOCK Score range: 0–100. Thresholds: BLOCK ≥ 85, WARN ≥ 40, ALLOW < 40.

POST/analyzeFull analysis with tiered access

Request Body

{
  "code": "console.log('hello')",
  "language": "javascript",
  "mode": "basic"
}
FieldTypeDescription
codestringCode to analyze required
languagestringLanguage hint
modestring"basic" (default) or "premium"
POST/scan-dependenciesAudit npm/pypi manifests for supply-chain risks
{
  "manifest": "{\"dependencies\":{\"event-stream\":\"3.3.6\"}}",
  "ecosystem": "npm"
}
POST/ciCI/CD pipeline YAML security audit
{
  "content": "permissions: write-all"
}

Error Codes

Error Handling

All endpoints return standard HTTP status codes.

StatusDescription
400Bad Request — missing or invalid parameters
401Unauthorized — missing or invalid API key
404Not Found — endpoint does not exist
413Payload Too Large — input exceeds 100KB limit
429Too Many Requests — rate limit exceeded
500Internal Server Error
